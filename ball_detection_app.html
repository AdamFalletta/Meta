Deploying to GitHub Pages

Since this is a single standalone HTML file, deploying to GitHub Pages takes less than 1 minute:

  1. Create a new repository on GitHub (e.g., ball-detector).
  2. Save this code as index.html in your project repository.
  3. Go to your repository Settings > Pages.
  4. Under Build and deployment, select Deploy from a branch and choose main / (root).
  5. Save and visit your live GitHub Pages link! Note: Camera permissions require HTTPS, which GitHub Pages provides by default.
