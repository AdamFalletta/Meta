Offline setup

  1. Serve this HTML from localhost (for example, python -m http.server 8000). Camera access usually will not work from a plain file:// page.
  2. YOLO: the YOLO browser library loads from esm.sh and YOLO26n model weights load directly from Hugging Face CDN (about 10 MB). No local model file is needed. The model host must permit browser CORS access.
  3. Transformers.js: its library loads from jsDelivr and the Xenova/yolos-tiny model weights/config download automatically from Hugging Face on first load.
  4. Offline means after setup: this single HTML file contains the interface and app code, and both engines download their model weights from CDNs on first load. For offline use, those assets must be cached by the browser or downloaded and hosted locally first. A standalone HTML file cannot register its own service worker; reliable offline use requires a small local server plus locally stored model/runtime files.

This demo filters detections to “sports ball.” Small, blurry, occluded, or fast-moving balls may be missed; tracking smooths movement but does not replace detection.
